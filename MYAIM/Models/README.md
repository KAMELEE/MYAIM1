# Models

نماذج البيانات (value types / SwiftData حسب الحاجة) تُعرَّف هنا:

`User` · `Goal` · `GoalStep` · `Category` · `Provider` · `Academy` ·
`Service` · `Course` · `Booking` · `Review` · `Favorite` · `Notification` · `Location`

تُبنى تدريجيًا مع الميزات التي تستهلكها (تبدأ في المرحلة 5 مع Home)،
مع فصل نماذج العرض (Domain models) عن أي DTOs خاصة بالـBackend مستقبلًا.
